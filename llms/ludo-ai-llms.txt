# Ludo.ai

> Ludo.ai generates production-ready game assets with AI: sprites and animated sprite sheets, pixel art, icons, UI, backgrounds, textures, 3D models with rigging and animation, sound effects, music, voices and video. It also helps plan games, from idea generation to a full game design document. Use it from the web app, the Ludo CLI, the MCP server, the REST API or the Unity plugin, all on one account and one set of credits.

- Web app and sign-up: https://app.ludo.ai
- The CLI, MCP server, REST API and Unity plugin are included on the Pro and Studio plans. The web app works on every plan.
- API, MCP and CLI calls always draw credits, including actions that are unlimited in the web app on Pro.

## Developers

- [Developers hub](https://ludo.ai/developers): every way to build with Ludo, and what a generation costs
- [Ludo CLI](https://ludo.ai/developers/cli): `npm install -g @ludoai/cli`, then `ludo login`. The recommended way to give coding agents (Claude Code, Codex, Cursor) access to Ludo: short help pages, local files passed by path, results saved to disk
- [MCP server](https://ludo.ai/developers/mcp): remote MCP endpoint `https://mcp.ludo.ai/mcp` for AI assistants that cannot run shell commands
- [REST API](https://ludo.ai/developers/api): base URL `https://api.ludo.ai/api`, header `Authorization: ApiKey YOUR_API_KEY` (create keys under API Keys in the web app). Generation endpoints are asynchronous: they return `202` with a job id, poll `GET /assets/jobs/{id}`
- [API reference](https://api.ludo.ai/api-documentation): every endpoint, parameter, model and credit cost
- [OpenAPI spec (JSON)](https://api.ludo.ai/api-documentation/openapi.json): machine-readable OpenAPI 3 description of the public API
- [Unity plugin](https://ludo.ai/developers/unity): generate assets from inside the Unity editor
- [API and MCP guide](https://ludo.ai/docs/api-mcp): setup and usage notes

## Features

- [Sprite Generator](https://ludo.ai/features/sprite-generator): character sprites from a prompt or reference image, animated into packed sprite sheets; pixel art, 8-direction sprites, motion transfer from video
- [Image Generator](https://ludo.ai/features/image-generator): 2D game art in a chosen style: backgrounds, icons, UI, portraits, card art, textures, with transparent PNG export
- [3D Generator](https://ludo.ai/features/3d-generator): text or image to textured 3D models (GLB), auto-rigging and animation
- [Audio Generator](https://ludo.ai/features/audio-generator): sound effects, looping music, ambiances, character voices and narration
- [Video Generator](https://ludo.ai/features/video-generator): animate a still image into a short MP4 clip with a motion prompt
- [Game Ideator](https://ludo.ai/features/game-ideator): turn keywords, genres or games you admire into game ideas with concept art
- [Project](https://ludo.ai/features/project): AI-assisted game design document editor
- [Ask Ludo](https://ludo.ai/features/assistant): conversational assistant for brainstorming, research and asset generation
- [Tutorial Generation](https://ludo.ai/features/tutorial-generation): a step-by-step development guide for your game in the engine you choose
